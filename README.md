# 《老人与海》——互动叙事游戏开发文档


## 文档说明

本文档为《老人与海》互动叙事游戏项目的完整开发文档。游戏基于海明威同名中篇小说改编，采用“选择推进剧情”的互动叙事模式，玩家通过在不同剧情节点做出选择来推动故事发展，最终走向多个不同结局。

文档共提供 **三个版本** 的设计方案，分别对应不同的开发复杂度与内容深度：
- **版本一（标准版）** ：5个结局，约12个选择节点，适合初次开发
- **版本二（扩展版）** ：8个结局，约20个选择节点，剧情分支更丰富
- **版本三（完整版）** ：12个结局，约30个选择节点，涵盖原著全部重要情节与象征主题


## 一、项目概述

### 1.1 项目名称
《老人与海》——命运之海（The Old Man and the Sea: Sea of Destiny）

### 1.2 项目定位
基于高中语文选择性必修上册课文《老人与海》（节选）改编的互动叙事类网页小游戏。通过选择驱动剧情的方式，让玩家亲身体验圣地亚哥老人与大海、大鱼、鲨鱼搏斗的历程，深入理解“人可以被毁灭，但不能被打败”的硬汉精神。

### 1.3 核心玩法
- 玩家在关键剧情节点做出选择
- 每个选择将影响后续剧情走向
- 最终抵达多个不同结局之一
- 支持多分支、多结局的开放式叙事结构

### 1.4 目标用户
- 高中学生（配合语文课程学习）
- 文学爱好者
- 互动叙事游戏玩家

### 1.5 技术兼容性
- **兼容Windows 7及以上操作系统**
- 支持主流浏览器：Chrome 49+、Firefox 45+、Edge（Chromium内核）、IE11（需额外polyfill）
- 采用HTML5 + CSS3 + JavaScript（ES5兼容语法）


## 二、游戏设计

### 2.1 故事背景
古巴老渔夫圣地亚哥已经连续八十四天没有捕到鱼了。曾经与他一起出海的孩子马诺林也被父母安排到了别的船上。第八十五天，老人独自一人驶向远海，决心捕获一条大鱼。在远海深处，一条巨大的马林鱼上钩了——比他的船还长两英尺。老人与大鱼僵持了两天两夜，最终将它杀死。然而在返航途中，鲨鱼群循着血腥味而来。老人与鲨鱼展开了殊死搏斗……

### 2.2 核心主题
- **硬汉精神**：“一个人可以被毁灭，但不能被打败。”
- **尊严与抗争**：胜利不由结果定义，而在于抗争本身的赤诚与执着
- **象征意义**：马林鱼象征人生的理想；鲨鱼象征无法摆脱的悲剧命运；大海象征变化无常的人类社会；狮子象征勇武健壮的精神力量

### 2.3 主要角色

| 角色 | 简介 |
|------|------|
| 圣地亚哥（老人） | 古巴老渔夫，消瘦憔悴但内心坚韧，连续84天一无所获仍不放弃 |
| 马诺林（男孩） | 曾与老人一起出海的孩子，因父母认为老人“背运”而离开，但始终关心老人 |
| 大马林鱼 | 身长18英尺、重约1500磅的巨型马林鱼 |
| 鲨鱼群 | 循血腥味而来的掠食者，先后多次袭击 |

### 2.4 游戏机制

#### 2.4.1 核心循环
```
剧情展示 → 出现选择 → 玩家点击选择 → 跳转至对应剧情 → 继续循环 → 抵达结局
```

#### 2.4.2 节点类型
- **剧情节点**：展示故事文本，无选择（过渡或结局）
- **选择节点**：展示故事文本 + 2-4个选项
- **结局节点**：展示结局文本 + 重新开始按钮

#### 2.4.3 游戏状态
- 当前节点ID
- 已做出的选择记录（用于解锁特定结局）
- 累计得分/状态值（可选，用于判定结局）

### 3.3 详细节点文本（版本一）

#### 节点1：八十四天一无所获
**场景**：古巴海岸边的小茅棚。清晨，老人醒来。

**文本**：
> 圣地亚哥已经连续八十四天没有捕到一条鱼了。最初四十天，一个叫马诺林的孩子和他一起出海，但孩子的父母说老人“背运”，让孩子上了别的船。如今，老人独自一人。今天是第八十五天——他该怎么做？

**选项**：
- A. **“每天都是新的一天。运气好当然更好，但我宁愿做到准确。那么运气来的时候你是有准备的。”**——继续出海
- B. **“我已经老了，八十四天一无所获，也许我该认命了。”** ——放弃出海

#### 节点2：第八十五天出海
**场景**：黎明前的海面。老人划着小船驶向大海。

**文本**：
> 天还没亮，老人已经把小船划出了港口。海面平静，远处有鸟群盘旋。他在黑暗中感受着海浪的节奏，思考着今天该去哪里。

**选项**：
- A. **“到远海去吧，到别人不敢去的地方。”** ——驶向远海深处
- B. **“就在近海碰碰运气吧，至少安全一些。”** ——留在近海

#### 节点3：大鱼上钩
**场景**：远海。钓竿猛然下沉。

**文本**：
> 绿色的竿子急遽地坠到水里。老人知道，一条大鱼正在吃钓尖上的沙丁鱼。他灵巧地握着钓丝，感到下面的分量越来越重。这是一条他从未见过的大鱼——比他想象中任何鱼都要大。

**选项**：
- A. **“不管它多大，我都要和它斗到底。”** ——坚持搏斗
- B. **“太大了……我斗不过它，割断钓线吧。”** ——放弃大鱼

#### 节点4：两天两夜的僵持
**场景**：海上。第二天傍晚。

**文本**：
> 大鱼拖着小船漂流了整整两天两夜。老人的左手在抽筋，后背被钓索勒出了血。他吃了一些生鱼来补充体力。大鱼依然没有浮出水面。老人想：“我拿它没有办法，它拿我也没有办法。”

**选项**：
- A. **“鱼啊，我会跟你奉陪到死。”** ——继续坚持
- B. **“我太老了，太累了……放它走吧。”** ——放弃大鱼

#### 节点5：杀死大鱼
**场景**：第三天。大鱼终于浮出水面。

**文本**（过渡节点，无选择）：
> 第三天，大鱼开始打转，最后银花花的肚皮翻出了水面。老人使尽平生的力气，将鱼叉刺进了大鱼的心脏。大鱼死了——身长十八英尺，重一千五百磅。老人把它绑在船边，升起帆，开始返航。

#### 节点6：返航途中——鲨鱼来袭
**场景**：返航途中。海面出现鲨鱼的鳍。

**文本**：
> 死鱼的血腥味在海水中扩散。第一条鲨鱼来了——它飞速逼近船艄，袭击大马林鱼。老人握紧了鱼叉。

**选项**：
- A. **“来吧，鲨鱼。人不是为失败而生的。”**——全力搏斗
- B. **“我已经太累了……随它去吧。”** ——放弃抵抗

#### 节点7：多次鲨鱼袭击
**场景**：深夜。鲨鱼群再次来袭。

**文本**：
> 鲨鱼一批又一批地到来。老人的鱼叉没了，刀子断了，最后连舵把也打断了。他精疲力竭，但鲨鱼还在撕咬着大鱼的肉。

**选项**：
- A. **“战斗到最后一刻。一个人可以被毁灭，但不能被打败。”** ——战斗到底
- B. **“够了……我已经尽力了。”** ——适时放弃

## 六、技术实现方案

### 6.1 技术选型

| 技术 | 用途 | 兼容性说明 |
|------|------|------------|
| HTML5 | 页面结构 | Win7支持 |
| CSS3 | 样式与动画 | 使用兼容性前缀 |
| JavaScript (ES5) | 游戏逻辑 | 不使用ES6+语法（如箭头函数、let/const可用但建议用var） |
| JSON | 剧情数据存储 | 原生支持 |

### 6.2 兼容Windows 7的注意事项

1. **浏览器要求**：
   - Chrome 49+（Win7最后支持版本）
   - Firefox 52+（Win7最后支持版本）
   - IE11（需额外polyfill）

2. **CSS兼容**：
   - 使用 `-webkit-`、`-moz-` 前缀
   - 避免使用 `grid` 布局（IE11不支持），使用 `flexbox` + `table` 降级
   - 字体使用系统字体栈

3. **JavaScript兼容**：
   - 使用 `var` 代替 `let/const`
   - 使用 `function() {}` 代替箭头函数
   - 使用 `""` 代替模板字符串
   - 使用 `XMLHttpRequest` 代替 `fetch`
   - 使用 `document.querySelector` 等标准DOM API
